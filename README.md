# Personal_Knowledge_Vault
# 📘 Personal Knowledge Vault (Vault Project)

**Personal Knowledge Vault** is a full-stack web application that allows users to securely manage their personal notes.  
The project uses **Spring Boot** for the backend and **React.js** for the frontend, with **JWT-based authentication** and **OAuth2 (Google Login)**.

---

## 1️⃣ Modules Overview

### 🔐 Authentication Module
- User Registration  
- User Login  
- User Logout  
- JWT-based authentication  
- Secured APIs using Spring Security  
- Axios for handling HTTP requests  
- OAuth2 Login (Google)

---

### 🖥️ Frontend Module (React.js)
- User-friendly UI for Login & Registration  
- Notes Dashboard  
- Create, Edit, Delete Notes  
- Add Notes, Favorite Notes & Save Notes  
- Secure API integration using JWT  

---

### 📝 Notes Management Module
- Create Notes  
- View All Notes (User-specific)  
- View Single Note  
- Update Notes  
- Delete Notes  
- Favorite Notes  

---

### ⚙️ Common Modules
- Global Exception Handling  
- Validation (Jakarta Validation)  
- Layered Architecture  
  - Controller  
  - Service  
  - Repository  

---

## 2️⃣ Getting Started

Follow the steps below to run the **Frontend + Backend** locally.

---

### 🔹 Step 1: Clone the Repository
```bash
git clone https://github.com/mlondhe69-art/Personal_Knowledge_Vault.git
cd Personal_Knowledge_Vault

##  2️⃣Frontend Setup (React.js)


### 🔹 Step 1: Navigate to the Frontend Folder
```bash
cd frontend

🔹 Step 2: Install Dependencies
npm install

🔹 Step 3: Start the React Application
npm start

🔹 Step 4: Access the Frontend

The frontend application will be available at:

http://localhost:5173

3️⃣ Backend Setup (Spring Boot)

Follow the steps below to run the Spring Boot backend locally.

🔹 Step 1: Open Backend Project

Open the backend project in Eclipse or IntelliJ IDEA

🔹 Step 2: Configure Application Properties

Configure the following in application.properties:

Database configuration

JWT secret and expiration settings

🔹 Step 3: Run the Backend Application
mvn spring-boot:run

🔹 Step 4: Access the Backend

The backend application will be available at:

http://localhost:8080
